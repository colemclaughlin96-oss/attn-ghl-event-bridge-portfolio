PROCESSING CONTRACT
The server bridge persists events, claims, evidence and send attempts; it does not call a language model or GHL itself. The existing native ChatGPT task owns generation and official ATTN MCP actions. Local development adapters simulate these boundaries. Do not invent callable tools from this document. Before production adoption, bind the reviewed development runner to supported native tools and verify its actual schemas.

The local InboundRunner accepts snapshot, generate, send, verify and optional notify adapters from its authenticated host; these names are JavaScript adapter interfaces, not new MCP tools. Default bounds are 45 seconds per run, 8 seconds per evidence read, 15 seconds per generation and 8 seconds per send. There are at most three visibility checks with 250ms then 500ms waits, two generation attempts per context, and two context refreshes. The total run budget bounds all work. The configured generation output budget is 650 tokens; complete output must still pass the current 1,500-character draft guard. Do not silently clip text to either limit.
