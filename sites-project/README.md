# Companion authentication facade

This folder contains the React/Vinext companion source for an owner-scoped MCP proxy. It forwards authenticated requests to a separately configured bridge. This is source for review, with original hosting bindings removed; no live Site is provisioned by this portfolio.

Inspect `package.json` for development and build commands. Configure the required environment and authentication integration for your own environment before running the facade. Backend tests run separately from the repository root.
